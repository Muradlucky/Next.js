## 1. ECC — «механики Мустафы»

**Что это.** [affaan-m/everything-claude-code](https://github.com/affaan-m/everything-claude-code), версия 2.2.3, лицензия MIT. Большой набор агентов (71), навыков (311), команд (97), хуков и правил для Claude Code. Сессия 28.10 скопировала 180 файлов в `ecc-study/source/` (с `LICENSE` и `UPSTREAM.txt` — MIT это позволяет) и написала 7 разборов.

**Пять главных выводов из разбора (сохраняю, чтобы не потерять):**
1. ECC — это не программа, а набор текстовых инструкций и нескольких скриптов. Сильнее всего — дисциплина передачи дел и проверок.
2. Почти вся автоматика ECC привязана к своему компьютеру (хуки, tmux, worktree, «наблюдатель»). В облако переносятся идеи и шаблоны, а не скрипты.
3. Базе на Google Docs не хватает трёх вещей: «карты» документов, списка отменённого с заменами и журнала причин решений.
4. **Агент, проверяющий сам себя, не работает.** Нужен отдельный проверяющий (или два независимых) + регрессионный набор тестов.
5. Популярные «агентные ОС» других авторов тоже рассчитаны на свой компьютер.

**План на изучение (15 тем)** лежит в `ecc-study/00-README.md`: агентная ОС, «совет» для спорных решений, Living Docs, общая память и передача дел, журнал решений, самообучение, контроль качества, экономия контекста, безопасность агентов, разбор почты, лиды, контент, сравнение с Anthropic Projects.

**Статус 13.11:** идёт сессия «Mark · механики Мустафы (ECC) в работу» — внедрение. Эту сессию не трогал.

**Риск:** `ecc-study/source/` — 91 тыс. строк чужого кода в публичном репозитории. Юридически ок (MIT), но это копия «на дату»: ECC обновляется, копия стареет. Для справки — нормально, для работы — брать свежую версию.

## 2. Каталоги агентов и skills

**Что это.** Ручной разбор `obra/superpowers`, `VoltAgent/awesome-claude-code-subagents`, `anthropics/skills`, `openai/skills` + свой субагент `assumption-mapping` (проверка допущений).

**Ценный вывод из разбора:** шаблонные бизнес-агенты VoltAgent — в основном списки ключевых слов, ссылаются на несуществующий «context manager» и содержат выдуманные цифры в примерах. Часть зашита на более слабую модель. То есть «каталог на 100 агентов» ≠ готовые сотрудники.

**Verdict:** разбор полезен как фильтр. Субагент `assumption-mapping` перед использованием прогнать на 2–3 реальных задачах.

## 3. Правила Claude Code («закон»)

**Что это.** Черновик на утверждение от 02.11:
- `CLAUDE.md` — как начинать любой чат: бытовой вопрос → ответ сразу; вопрос о системе → найти документ «Читать первым» и следовать ему.
- `/orch` — ручной обход системы; субагент `reviewer` — независимый проверяющий.
- `docs/claude-code-rules.md` — справочник: поверхности запуска, слои конфигурации, почему Claude нарушает правила, граница роли оркестратора, hook `guard.py` (блокировка опасных действий по содержимому), как создавать запланированные задачи.

**Verdict:** сильная идея — **«репозиторий как носитель закона»**: правила, которые Claude Code читает автоматически, а не по памяти. Но черновик написан до переезда ботов на Mac 12.11. Перед утверждением — сверить с текущим каноном.

**Важно для Android (см. ниже):** именно этот подход решает проблему «с телефона не работает» — но только в **приватном** репозитории.

## 4. Оптимизация: «меньше проверок»

**Что это.** Предложение из 6 пунктов («молчание = да» через 48 часов, светофор 🟢🟡🔴, одна очередь «Ждёт Мурада», шапка карточки до 5 строк, параллельная работа, Claude проверяет сам — Мурад выборочно) + HTML-дашборд TickTick.

**Verdict:** идеи совпадают с выводом ECC №4 и с тем, что сводка теперь делает каждое утро («одна очередь вопросов В1–В5»).

## Новая механика 13.11: «Утренняя сводка»

Запланированная задача, каждый день в 06:52 (Bangkok), **каждый раз новый чат** + push на телефон.

| Блок | Что внутри |
|---|---|
| 🔥 Главное | 5–7 новостей: Таиланд и Азия → мир → рынки → Россия глазами независимых источников. Формат «Факт → Контекст → Влияние», 2 независимых источника на цифры |
| 📊 Сигналы рынков | USD/THB, EUR/THB, Brent, золото, S&P 500, Bitcoin + до 3 сигналов по Таиланду |
| 🤖 Claude: новое | Changelog Claude Code и новости Anthropic; по понедельникам — итог недели и приёмы сообщества |
| 🧭 Наше состояние | Сессии (ждут / в работе / упали / готово), запланированные задачи, карточки с тегами |
| 🔔 Напоминалка | Всё, что висит 5+ дней, — каждый день, пока не закроют. **Отчёт выдаётся всегда**, даже если ничего не сделано |
| ❓ Вопросы | В1–В5, ответ одной строкой |

Источники и правила отбора — утверждённые ранее (23.10 и 02.11): Reuters/AP для обнаружения, первичные данные центробанков и статистики, без провластных российских СМИ и Telegram.

**Ограничение:** задача создана из облачной сессии, и коннектор TickTick к ней не прикрепился. Без него сводка выдаёт новости и состояние сессий, но не видит карточки. Решение — добавить коннектор TickTick в настройках задачи в приложении.

## Android: почему с телефона «не всё работает»

1. Чат с телефона — это **облачная** сессия. Папка «Claude» на Mac стоит в списке Remote Control, но Mac не отдаёт её облачным сессиям.
2. Боты, чьи инструкции лежат на Mac, работают, только пока Mac не спит.
3. Сессии, запущенные на самом Mac через Remote Control, на телефоне видны и работают — пока Mac бодрствует.

**Рекомендация — гибрид:** всё, что можно, — в облако (правила в **приватный** репозиторий или Google Drive, облачные запланированные задачи); Mac — только для локального. Подробности и шаги — в карточке задачи «📱 Android».
