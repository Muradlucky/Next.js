# Утренняя сводка — механика

Ежедневная визуальная сводка новостей: мир → война → Азия → Таиланд и бат → Россия → ИИ для бизнеса. Только проверенные факты, с графиками и архивом выпусков.

> Репозиторий публичный, поэтому здесь только шаблон и инструменты. Правила (`RULES.md`), выпуски и ссылка на страницу лежат в приватном артефакте «Утренняя сводка».

## Как устроено

| Часть | Где | Что делает |
|---|---|---|
| Страница | артефакт, `index.html` (копия здесь) | Рисует выпуск из JSON: «За 30 секунд», рынки со спарклайнами, разделы, график бата, валюты Азии, проверка Telegram-сигналов, архив |
| Правила | артефакт, `RULES.md` | Что брать, в каком порядке, какие источники, как проверять, схема JSON. Меняются без правки кода |
| Данные рынков | `fetch_markets.py` (копия в артефакте `tools/`) | Yahoo Finance (8 рынков, 6 индексов Азии) + курсы ЕЦБ (10 валют) + официальный курс Банка России |
| Выпуски | артефакт, `data/ГГГГ-ММ-ДД.json` + `data/issues.json` | Один файл на день; список — для архива |
| Запуск | запланированная задача, 06:52 Bangkok, каждый раз новый чат + push | Читает `RULES.md`, собирает выпуск, публикует только два JSON-файла |

**Почему так:** запуск пишет только JSON (~10–15 тыс. токенов), а не HTML целиком. Страница не меняется, архив копится сам, дизайн правится один раз.

## Проверить локально

```bash
python3 -I fetch_markets.py /tmp/markets.json   # данные рынков
python3 -m http.server --directory <папка с index.html и data/> 8765
```

## Известные ограничения (13.11.2026)

- Из облака недоступны страницы AP и Reuters — используются перепечатки.
- Индекс SET (Таиланд) в Yahoo не отдаётся — нужен другой источник.
- Запуск по расписанию не видит TickTick и список сессий: коннекторы к задаче из чата не прикрепляются. Блок «Наше состояние» — зона Kim.
