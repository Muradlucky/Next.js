## Общие наблюдения

### 1. Это другой класс инструментов
Видео-стек (FFmpeg, Remotion…) — это программы. Здесь почти всё — **agent skills/plugins**: тексты-инструкции и hooks, которые меняют поведение Claude. Исключения: REA и Scrapling (MCP-серверы/библиотеки) и Onyx (целая серверная платформа).

### 2. Stars ≠ quality — аномалии
Для сравнения: yt-dlp набрал 205k звёзд за 6 лет.

| Repo | Возраст | Stars | Forks |
|---|---|---|---|
| REA | 7 месяцев | 440k | 109k |
| Ponytail | 5 месяцев | 186k | 10k |
| UI/UX Pro Max | 11 месяцев | 146k | 15k |

440k звёзд за 7 месяцев — это уровень крупнейших проектов GitHub за всю историю. Доказать накрутку нельзя, но такие цифры — **маркетинговый сигнал, а не показатель качества**. Оценивать нужно по коду, а не по звёздам.

### 3. Риски установки
- **Hooks выполняют код на каждом промпте.** Например, Ponytail запускает `node` на SessionStart, UserPromptSubmit и SubagentStart.
- **Auto-update:** плагин может измениться уже после того, как мы его проверили. Включать auto-update только для проверенных.
- **Токены.** Каждый skill добавляет своё описание в контекст, hooks — текст в каждый промпт. 10 плагинов сразу = заметно больше расход токенов. Учитывая, что лимит уже закончился, — ставить по одному и только нужные.
- **Права агента.** Plugin работает с теми же правами, что и Claude Code: файлы, команды, сеть.

## Разбор по каждому

### 01. REA — Reverse Engineer Anything ❌
**What it is.** MCP-сервер, который подключает к агенту инструменты reverse engineering: Ghidra, Hopper, IDA, JADX, Frida, анализ Electron/.NET/сайтов. Идея: «увидел фичу в чужом приложении — разберись, как она сделана».

- MIT, TypeScript, ~7 500 файлов. Очень высокая скорость изменений: 100 коммитов за ~1 день.
- Установка `npx rea-agents setup` меняет конфигурацию агента, может ставить Hopper.
- **Юридически:** reverse engineering чужих приложений может нарушать лицензионное соглашение (EULA) и законы. Собственный DISCLAIMER проекта ограничивает использование: исследования безопасности, свой софт, анализ с разрешения.
- **Для нас:** к видео и сценариям отношения не имеет. Не ставить.

### 02. Ponytail — «ленивый senior-разработчик» 🟡
**What it is.** Один большой prompt (`skills/ponytail/SKILL.md`) + команды `/ponytail-review`, `/ponytail-audit`. Агент сначала ищет, что уже есть в проекте, и пишет минимум нового кода, не жертвуя проверками и безопасностью.

- MIT. Есть hooks и «band» над промптом: стоимость задачи, токены, время агента; локальная страница Board со статистикой.
- Проверил hooks: внешних сетевых запросов не нашёл — метрики считаются локально, таблица цен зашита в код.
- **Для нас:** полезен, когда начнём писать много кода (pilot Remotion/HyperFrames). Счётчик стоимости — плюс при нашей проблеме с токенами. Но hooks сами добавляют текст в каждый промпт. **Попробовать позже, в одном проекте.**

### 03. Hallmark ⏸
**What it is.** Design skill от Together AI: строит веб-страницы так, чтобы они «не выглядели сгенерированными». 50 тем-«материалов», жёсткие проверки (контраст, focus, мобильная вёрстка, «не выдумывать факты»), 755 фото со свободной лицензией.

- MIT, 250 MB (много картинок).
- **Для нас:** только если будем делать сайт/лендинг. Для видео не нужен.

### 04. Humanizer ✅ (рекомендую первым)
**What it is.** Один файл `SKILL.md`: переписывает текст, убирая признаки AI-письма. Основан на статье Wikipedia «Signs of AI writing», 26 паттернов: «не X, а Y», громкие концовки, «давайте разберёмся», лишние тройки и тире, «продающий» язык.

- MIT, всего 14 файлов, **исполняемого кода практически нет** → самый безопасный из десяти.
- Цель — читаемость для людей, а не обход AI-детекторов (README прямо говорит, что детекторы его текст всё равно ловят).
- Примеры на английском, но skill явно говорит, что те же конструкции есть в любом языке. **Нужен тест на русском.**
- **Для нас:** прямо для сценариев роликов, подписей и постов: Claude пишет черновик → Humanizer делает его живым.

### 05. «Onyx» / taste-skill ❌ — ошибка в посте
В карточке №5 смешаны **два разных проекта**:
- **Название и описание** («собирает свой чат с ИИ, подключённый к базам знаний») — это [onyx-dot-app/onyx](https://github.com/onyx-dot-app/onyx): open-source AI-платформа (бывший Danswer), 33k stars. Лицензия: MIT, кроме папок `ee/` — там коммерческая Enterprise License. Это тяжёлая серверная система (Docker, базы данных) — для личного использования избыточна.
- **Ссылка** ведёт на [senlindesign/taste-skill](https://github.com/senlindesign/taste-skill): маленький skill `/taste`, который через Playwright разбирает дизайн любого сайта (токены + «почему так»). 453 stars, 2 автора, последний коммит — июль 2026, **нет лицензии** (юридически это значит «все права защищены», переиспользовать код нельзя).
- **Для нас:** ни то, ни другое сейчас не нужно. Сам факт ошибки — повод не доверять подборке вслепую.

### 06. Impeccable ⏸
**What it is.** «Дизайн-словарь» для агента от Paul Bakaus: команды `polish`, `bolder`, `critique`, `audit`, плюс 62 детерминированных правила, которые ловят типичный AI-дизайн (Inter везде, фиолетовые градиенты, карточки в карточках) — без LLM и API-ключей.

- Apache-2.0, очень активный. `npx impeccable install` меняет файлы проекта.
- **Для нас:** для веб-интерфейсов. Для видео — косвенно (если выберем HyperFrames, кадры там — HTML). Позже.

### 07. UI/UX Pro Max ⏸
**What it is.** Генератор design system: CSV-базы стилей, палитр, шрифтовых пар и UX-правил + Python-скрипты поиска по ним. 78 авторов, много переводов README.

- MIT. Аномально много звёзд (146k).
- **Для нас:** для сайтов. Базы палитр и шрифтовых пар можно использовать как справочник для оформления роликов.

### 08. Last30Days ✅ (для поиска тем)
**What it is.** Research-skill: по запросу собирает, что люди обсуждали за последние 30 дней на Reddit, X, YouTube (транскрипты через yt-dlp), Hacker News, Polymarket, GitHub; опционально TikTok, Instagram, Threads. Ранжирует по реальной вовлечённости (лайки, апвоуты), а не по SEO.

- MIT, Python 3.12+. Без настройки работают Reddit, HN, Polymarket, GitHub.
- **Нюансы:**
  - X по умолчанию читается **через cookies вашего браузера** (неофициальный клиент) — skill спрашивает разрешение. Это риск для аккаунта X; лучше отказаться.
  - TikTok/Instagram — через платный сервис ScrapeCreators: 10 000 бесплатных запросов, дальше оплата по факту.
  - Первый запуск предлагает доустановить дополнительные CLI-утилиты.
- **Для нас:** самый полезный для **сценариев**: «о чём сейчас говорят по теме X» → идеи и факты для ролика. Начать только с бесплатных источников, cookies не давать.

### 09. Scrapling 🟡
**What it is.** Зрелый Python-фреймворк для web scraping (с 2024 года): быстрые HTTP-запросы, stealth-браузеры, обход Cloudflare Turnstile, пауки, экспорт в Markdown, MCP-сервер для агентов.

- BSD-3, 48 авторов, активен. README заполнен рекламой прокси и сервисов решения CAPTCHA (affiliate).
- **Для нас:** пригодится для сбора данных с открытых сайтов. **Для Instagram не подходит:** там нужен логин, а обход защиты от ботов нарушает правила платформы и грозит блокировкой аккаунта. Для Instagram есть отдельные инструменты (см. PLAN.md, этап 8).

### 10. Diagram Design ✅ (для explainer-роликов)
**What it is.** Skill, который по описанию словами делает аккуратную диаграмму в одном HTML-файле: 45 типов (архитектура, квадранты, последовательности…). Может подстроиться под палитру и шрифты сайта.

- MIT, активен.
- **Для нас:** готовая графика для объясняющих роликов. Её HTML можно напрямую вставить в HyperFrames (там кадр — тоже HTML) или сделать скриншот для Remotion.

## Recommendation

| Когда | Что ставить |
|---|---|
| Сейчас, вместе с pilot | **Humanizer** (тест на русском сценарии) |
| Когда начнём писать сценарии регулярно | **Last30Days** (только бесплатные источники, без cookies) |
| Для explainer-роликов | **Diagram Design** |
| Если будем много программировать | Ponytail (в одном проекте, с наблюдением за токенами) |
| Если понадобится сайт | Impeccable или Hallmark (один из них), UI/UX Pro Max как справочник |
| Не ставить | REA, Onyx, taste-skill |

Правила установки:
1. По одному плагину; после установки — проверить, что изменилось (`/plugin`, `~/.claude/`).
2. Перед установкой — прочитать `SKILL.md` и hooks.
3. Auto-update — только для проверенных.
4. Ничего не давать из браузерных cookies и API-ключей без необходимости.
